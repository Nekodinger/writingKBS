# English Writing Assessment v2

Full-stack starter: GitHub Pages frontend + Google Apps Script API + Google Sheets + Google Docs/Drive.

Includes Student Panel, Teacher Panel, assessment/template settings, progress monitoring, UUID sessions, activity logging, timer, clipboard blocking, fullscreen/visibility monitoring, and automatic Google Docs submission.

Read `apps-script/README_SETUP.txt` for setup.

Teacher panel:
`?panel=teacher`

Google Docs are generated only after submit. Students are never granted document access; the configured teacher email is added as Viewer.

Client-side lockdown is deterrence/detection, not a guaranteed operating-system lockdown.
